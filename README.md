This repository hosts a static GitHub Pages portfolio for Power BI and business analytics case studies.

https://mpatrick456.github.io/data-bi-/

## Pages

- `index.html` – portfolio landing page
- `learning-analytics.html` – Project 03: L&D Analytics Dashboard
- `energy-debt-repayment.html` – Project 04: Energy Debt Repayment Analysis
- `docs/ld-dashboard-case-study.md` – written case study for the L&D project
- `docs/energy-debt-case-study.md` – written case study for the energy debt project
- `docs/portfolio-cv-summary.md` – CV and cover letter wording

## How to enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages** from the left menu.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch: `main`.
6. Select folder: `/root`.
7. Save.

GitHub normally shows the Pages URL after the deployment is complete.
